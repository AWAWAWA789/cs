# 第二十二阶段 · 历史训练与案例库方案（Step 2）

> **核心目标**：从过去两年步枪千百战单品历史中，沉淀吸货识别案例库 + 训练规则权重，
> 让"吸货侦察兵"用得越久越准。

## 一、战略定位

**这是产品护城河**——案例库 + 训练权重 = 别人复制不了的资产。

```
分析 → 落盘案例（good_id/特征/评分/时间）
  ↓ N天后回看价格走势
标注（涨=正样本 吸货确认 / 跌=负样本 误判）
  ↓
训练规则权重 + 构建 DTW 案例库
  ↓
下次分析时：当前特征 → 检索历史相似案例 → 返回"上次类似情况后涨了 X%"
```

## 二、复用与新建清单

### 可复用（已有）
- `/rank/items` type=步枪 → 候选池
- `/item/batch-price` → 价格筛选（300-2500）
- `/info/chart` period=730 → 两年日线
- `cache.py` 命名约定 → 落盘格式
- `state_vector` 特征定义（~20 维）
- `index_builder` 落盘+增量+查询骨架
- `knn_search` / `dtw_search` 检索内核
- `walk_forward` 滚动切分脚手架
- `calibration_store` JSONL 持久化范式

### 需新建
1. **单品 OHLC 落盘缓存层**（`item_cache.py`）
2. **批量回填编排器**（`backfill.py`）
3. **案例库存储**（`case_store.py`，good_id 维度 JSONL+parquet）
4. **标注模块**（`labeling.py`，事后回看生成标签）
5. **训练模块**（`trainer.py`，规则权重拟合 + 案例库构建）
6. **在线推理入口**（`case_retriever.py`，加载训练好的案例库→查询）

## 三、数据契约

### 案例样本（case_store 单条记录）
```python
{
    "case_id": "rifle_2_20240315",          # {category}_{good_id}_{date}
    "good_id": "2",
    "good_name": "AK-47 | 红线",
    "category": "rifle",
    "timestamp": "2024-03-15",              # 分析时点
    "period": "1day",
    # 特征向量（K线 6 项 + 库存 4 项 + 原始统计）
    "features": {...},                      # 来自 accumulation + inventory_signals
    "kline_score": 0.72,
    "inventory_score": 0.65,
    "fused_score": 0.78,
    "pattern": "strong",
    # 标注（事后回看填充）
    "label": "positive",                    # positive/negative/neutral
    "future_return_7d": 0.12,               # 7 天后收益
    "future_return_30d": 0.25,              # 30 天后收益
    "max_drawdown_30d": -0.05,
    "labeled_at": "2024-04-14",
}
```

### 落盘路径
```
data/
├── item_cache/                    # 单品 OHLC 落盘
│   └── rifle/
│       └── {good_id}_1day.parquet
├── cases/                         # 案例库
│   ├── rifle_cases.jsonl          # 全量案例（append-only）
│   └── rifle_cases_labeled.parquet # 已标注案例（训练用）
└── trained/                       # 训练产物
    ├── rifle_rule_weights.json    # 拟合后的规则权重
    └── rifle_case_index.parquet   # DTW/KNN 案例索引
```

## 四、实施步骤（8 步）

### Step 2.1 · 候选池采集
- 调 `/rank/items` type=步枪，分页拉全量
- 调 `/item/batch-price` 筛选 300-2500 元
- 落盘 `data/candidates/rifle_candidates.json`

### Step 2.2 · 单品 OHLC 落盘
- 新建 `src/data/item_cache.py`：`save_item_ohlc` / `load_item_ohlc`
- 路径：`data/item_cache/{category}/{good_id}_{period}.parquet`
- 新建 `src/data/backfill.py`：批量回填编排器（含 1req/s 限速 + 进度）

### Step 2.3 · 案例库存储
- 新建 `src/scenario_engine/case_store.py`
- `save_case(case)` → append JSONL
- `load_cases(category)` → 返回 DataFrame
- `update_label(case_id, label, future_returns)` → 标注回写

### Step 2.4 · 标注脚本
- 新建 `src/scenario_engine/labeling.py`
- `label_case(case, ohlc_df, horizon=30)` → 事后回看
- 标签规则：30 天涨幅 > 15% = positive，跌幅 > 10% = negative，否则 neutral
- CLI 入口：`python -m src.scenario_engine.labeling --category rifle --horizon 30`

### Step 2.5 · 训练模块
- 新建 `src/scenario_engine/trainer.py`
- `fit_rule_weights(cases)` → sklearn LogisticRegression 拟合 6+4 项特征权重
- `build_case_index(cases)` → 复用 index_builder 构建 DTW/KNN 索引
- 落盘：`rule_weights.json` + `case_index.parquet`

### Step 2.6 · 在线推理
- 新建 `src/scenario_engine/case_retriever.py`
- `load_trained(category)` → 加载训练产物
- `retrieve_similar(features, top_k=5)` → KNN 检索 + 返回历史命中率
- 新端点：`GET /accumulation/similar-cases?good_id=X&period=1day`

### Step 2.7 · 前端展示
- AccumulationPage 加「历史相似案例」面板
- 显示：top-5 相似案例（时间/标的/评分/事后涨跌）
- 显示：训练命中率统计（案例库 >100 条后展示）

### Step 2.8 · 测试与验证
- case_store / labeling / trainer 单元测试
- 端到端：候选池→落盘→切片→标注→训练→推理

## 五、关键决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 样本切片粒度 | 每 7 天一个样本点 | 平衡样本量与冗余 |
| 标注窗口 | 30 天 | 饰品主力吸货周期通常 1-3 月 |
| 正样本阈值 | 30 天涨幅 > 15% | 千百战品波动适中 |
| 训练算法 | LogisticRegression | 可解释 + 小样本友好 |
| 案例索引 | KNN（欧氏+z-score） | 复用现有 index_builder |
| 库存数据 | 不参与训练（无两年历史） | 仅 K 线特征训练，库存用于实盘融合 |

## 六、里程碑

| 里程碑 | 案例库规模 | 预期命中率 |
|---|---|---|
| MVP | 100 条 | 50%（基线） |
| 启动 | 500 条 | 55% |
| 可用 | 1000 条 | 60%（目标） |
| 成熟 | 5000 条 | 65%+ |

## 七、验证标准

- 候选池：≥100 个步枪千百战单品
- 落盘：每个单品 730 天日线 parquet
- 案例库：滑动切片 ≥5000 样本（100 品 × 50 切片）
- 标注：自动回看生成 positive/negative/neutral
- 训练：规则权重从经验值收敛到数据驱动值
- 推理：相似案例检索 + 命中率返回
- 前端：历史案例面板正常渲染
