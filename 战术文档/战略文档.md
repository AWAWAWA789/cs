# CSQAQ 饰品市场纯价格行为量化策略框架 — 战略文档

> **版本：** v1.4  
> **制定日期：** 2026-07-27  
> **生效日期：** 2026-07-28（情景质量条款生效）  
> **生效状态：** 已生效，未经正式修订流程不得变更  
> **适用范围：** 基于 CSQAQ API 的 CS:GO/CS2 饰品市场各子指数（手套、匕首、步枪等）的纯价格行为量化策略框架

---

## 愿景陈述

构建一个**通用、可迁移、不依赖成交量**的纯价格行为量化策略框架，能够适配 CSQAQ 饰品市场任意子指数；通过识别庄家主导的结构性交易机会，在不同板块、不同时间窗口上生成可解释的多头信号，实现长期超越买入持有的风险调整后收益。

> 手套板块是当前战术验证的第一个场景，而非战略终局。

## 完美目标（Perfect Goal）

在现有回测框架之上，升级为一个**面向未来一周交易的“双轨情景预判引擎”**：

1. **输入**：当前市场状态向量，涵盖趋势强度、波动结构、Swing 位置、信号质量、多时间框架（日线 / 4h / 1h）共振关系。
2. **输出**：**2–4 种高概率未来一周走势情景，通常保持 3 种**。每种情景包含：
   - 发生概率（经贝叶斯校准后必须具有实际决策价值，杜绝 1% 级别的“凑数”概率）；
   - 关键价位（支撑 / 阻力 / 目标位）；
   - 浪形草图（基于波浪理论，不画每根 K 线，但精细度足够支撑决策）；
   - 交易建议（是否开仓、方向、止损、目标、仓位比例）。
3. **概率质量门槛**：采用**动态概率下界**机制，根据候选情景分布自适应设定入选门槛：
   - 相对下界 = `max(1 / 候选情景数, 0.10)`；
   - 动态下界 = 第 3 或第 4 大概率情景的 50%–60%；
   - 绝对硬底 = 0.05（5%），低于此值视为无信息价值；
   - 最终入选阈值 = `max(相对下界, 动态下界, 绝对硬底)`；
   - 若按阈值筛选后不足 2 条，则按概率排名强制补足 2 条并重新归一化；若超过 4 条，仅保留前 4 条。
4. **双轨生成机制**：
   - **历史相似性轨道**：基于 KNN + DTW + K-Means 在历史数据中寻找相似状态，生成“历史重演”情景；
   - **模板匹配轨道**：基于预定义技术分析 / 波浪理论模板（如三浪延伸、三角整理、头肩底、旗形整理等）生成“理论推演”情景。
5. **深度融合**：两条轨道通过冲突检测、概率加权、模板动态权重、多时间框架状态融合，输出最终情景集合。
6. **性能优化**：预计算历史状态索引，保证实时响应；贝叶斯概率校准减少历史频率偏差。
7. **人机交互**：提供浏览器可视化界面，实时展示当前状态、相似历史片段、匹配模板、未来情景草图与交易建议。
8. **AI 边界**：LLM 仅基于算法已生成的结论进行自然语言解释与走势草图绘制，**不参与核心判断**，避免模型能力波动影响决策稳定性。

> 完美目标不是一次实现，而是通过后续阶段逐步逼近。

## 成功指标

### 对应 G1（通用框架）
| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 子指数切换成本 | ≤ 1 个配置项 | 切换标的只需修改 `sub_index_id` 或名称 |
| 特征计算无硬编码标的 | 100% | 所有特征模块不依赖具体板块名称或 id |
| 框架可扩展性 | 支持 ≥3 个子指数 | 手套验证后，可快速迁移到匕首、步枪等 |
| 策略参数可配置 | 全部外置 | Swing 窗口、斐波那契容差、信号阈值等可配置 |

### 对应 G2（手套验证）
| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 累计超额收益率（相对买入持有） | > 0% | 策略最终净值减去同期买入持有净值 |
| 夏普比率 | > 0.8 | 4h 周期年化，无风险利率按 0 简化处理 |
| 最大回撤 | < 35% | 中高风险偏好下的可接受上限 |
| 胜率 | > 40% | 盈利交易次数占比 |
| 盈亏比 | > 1.5 | 平均盈利 / 平均亏损 |

### 对应 G3（特征库）
| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 特征覆盖率 | 100% | 至少实现 Swing、斐波那契、Pin Bar、吞没、流动性猎杀、OB、FVG、Breaker、Mitigation |
| 信号可解释性 | 每笔交易附带理由标签 | 例如 "0.618 + Pin Bar + 结构确认" |
| 消融实验覆盖率 | 5 组以上 | 单独验证每个特征模块的贡献 |

### 对应 G4（双环境部署）
| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 双环境运行一致性 | 相同输入输出完全一致 | 本地与 TRAE 跑同一版本代码，回测结果差异 < 1e-6 |
| 单元测试覆盖率 | > 70% | 核心特征与回测逻辑均有测试 |
| 数据可复现性 | 固定随机种子与缓存 | 任何人拿到 ApiToken 都能复现相同结果 |

### 对应 G5（双轨情景预判引擎）
| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 输出情景数量 | 2–4 条，通常 3 条 | 数量与高概率必须同时满足，绝不能低于 2 条 |
| 情景概率质量 | 入选情景概率 ≥ 动态下界 | 动态下界 = `max(1/n, 0.10, p3 × 0.5)`，杜绝 1% 级别的凑数情景 |
| 最低概率硬底 | ≥ 5% | 低于 5% 的概率对交易决策无信息价值 |
| 概率分布合理性 | 无单情景概率 > 95% 的“寡头”分布 | 避免出现 97% vs 1% × 3 的极端分布；必要时分流或强制补足 |
| 情景多样性 | 尽量 ≥ 2 种不同方向 | 在市场状态允许时，输出应覆盖至少两种不同方向；不强制引入低概率 filler |
| 一周方向胜率 | ≥ 55% | 按概率加权后的主要方向与未来 5–7 根 K 线实际方向一致 |
| 双轨贡献度 | 均有显著贡献 | 历史相似性与模板匹配各自在 ≥30% 的场景中成为主导依据 |
| 核心判断去 LLM 化 | 100% | 概率、方向、关键价位、仓位建议均由算法输出，LLM 只做解释 |

| 多时间框架融合 | 3 个周期 | 日线、4h、1h 状态均参与融合 |

## 关键约束

| 约束类型 | 具体内容 | 级别 |
|---------|---------|------|
| 数据约束 | 禁止使用成交量字段 `v`，所有信号仅基于 OHLC 与时间 | 红线 |
| 数据约束 | 仅使用 2024-01-01 00:00:00 UTC 之后的 K 线数据 | 红线 |
| 数据约束 | 主交易周期为 4h，辅助周期不超过 1d | 红线 |
| 框架约束 | 策略框架不得硬编码任何子指数或单品信息 | 红线 |
| API 约束 | CSQAQ 普通接口限流 1 次/秒，必须实现本地缓存 | 底线 |
| API 约束 | ApiToken 与 IP 白名单绑定，不得硬编码 | 底线 |
| 环境约束 | 代码必须同时兼容本地环境与 TRAE 环境 | 底线 |
| 风险约束 | 策略方向默认为只做多，不做空 | 默认规则 |
| 风险约束 | 中高风险偏好，允许较大回撤换取收益弹性 | 方向 |
| 情景预判约束 | 核心判断（概率、方向、关键价位、仓位）必须由算法输出，LLM 仅做解释与可视化 | 红线 |
| 情景预判约束 | 所有预判基于 OHLC 与时间，禁止引入成交量 | 红线 |
| 情景预判约束 | 波浪理论草图必须遵循基本数浪规则，禁止为了视觉效果违反规则 | 红线 |
| 情景预判约束 | 预计算索引必须可增量更新，避免每次全量重建 | 底线 |
