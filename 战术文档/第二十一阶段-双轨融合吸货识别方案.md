# 第二十一阶段 · 双轨融合吸货识别方案

> **核心信念**：K线会骗人（主力可以做线），库存不会骗人（货真在谁手里）。两者交叉验证，才有可信判断。

## 一、目标

将「K线行为评分」与「库存行为评分」融合为统一吸货评分，消灭单轨误判，为后续历史训练与 LLM 归因打地基。

## 二、架构

```
输入：单品 good_id + 周期
  │
  ├── K线行为轨 ──► accumulation_detector.rule_engine_score
  │     特征：量价背离/价格位置/横盘/底部抬高/波动率收缩/量能趋势
  │     输出：kline_score (0-1) + 6 项子分
  │
  ├── 库存行为轨 ──► inventory_signals.compute_inventory_signals
  │     特征：TOP3集中度/近7日净买入/主力跨品协同/团队置信度
  │     输出：inventory_score (0-1) + 4 项子分
  │
  └── 融合层 ──► fuse_scores
        规则：双轨同向加分，单轨触发减分
        输出：fused_score (0-1) + 阶段判定 + 证据链
```

## 三、融合规则（核心）

| K线 | 库存 | 融合分 | 含义 |
|---|---|---|---|
| 高 | 高 | kline×0.6+inv×0.4+0.1 | 强信号（主力明牌吸货）|
| 高 | 低 | kline×0.6+inv×0.4-0.05 | 弱信号（可能下跌中继）|
| 低 | 高 | kline×0.4+inv×0.6+0.15 | 隐蔽吸货（最稀缺）|
| 低 | 低 | kline×0.5+inv×0.5 | 无信号 |

阈值：≥0.6 吸货 / ≤0.3 出货 / 中间中性。

## 五、数据契约

### 库存特征（inventory_signals.compute_inventory_signals）

输入：`holders: list[dict]`, `trends: list[dict]`, `team_confidence: float | None`

输出：
```python
{
    "top3_concentration": float,   # TOP3 持仓占比 (0-1)
    "net_inflow_7d": float,        # 近7日净买入量（正=加仓）
    "holder_active_ratio": float,  # 活跃主力占比（近7日有变动）
    "team_confidence": float,      # 团队置信度（无团队数据=0.5）
    "inventory_score": float,      # 库存综合分 (0-1)
    "signals": {                   # 4 项子分
        "concentration": float,
        "net_inflow": float,
        "holder_activity": float,
        "team_synergy": float,
    },
}
```

### 融合端点响应（POST /accumulation/analyze-fused）

```python
{
    "good_id": str,
    "period": str,
    "fused_score": float,          # 融合吸货评分
    "phase": "accumulation|distribution|neutral",
    "kline_score": float,
    "inventory_score": float,
    "kline_signals": {...},        # 6 项 K线子分
    "inventory_signals": {...},    # 4 项库存子分
    "fusion_pattern": str,         # "strong|weak|hidden|none"
    "evidence": [str],             # 证据链（人话）
    "data_source": str,
}
```
